# Iron Man Pomodoro (Chrome Extension)

Iron Man–themed Chrome extension that encourages users to take stretch/movement breaks during study sessions.  
- Built with HTML, CSS, and JavaScript  
- Integrates a third-party Yoga API to display pose names and images  
- Focus on simple user flows so starting a session and viewing poses takes only a few clicks  

## Status
In progress: core functionality working; continuing to refine UI and add features.
